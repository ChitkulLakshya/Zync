# Governance

## Maintainers

Zync is maintained by the ZYNC Team (contact: consolemaster.app@gmail.com).
Maintainers have write access to `main` and can merge approved PRs.

## Decision-making

- **Design/architecture changes**: proposed via an issue or PR; a maintainer
  must approve before merge.
- **Breaking changes**: require a documented migration path and a CHANGELOG
  entry.
- **Security-sensitive changes**: reviewed by at least one maintainer with
  security context.

## Contribution rights

Contributions are welcome under the
[Contributor Covenant Code of Conduct](docs/CODE_OF_CONDUCT.md). By submitting
a PR, you agree to license your contribution under the project's
[AGPL-3.0](LICENSE) license.

## Releases

`vX.Y.Z` tags trigger the web release workflow. See
[.github/workflows/release.yml](.github/workflows/release.yml).
