# Zync Android Native

> **⚠️ Experimental — not part of the official release.**
>
> Kotlin/Jetpack-Compose client for Zync. This is a work-in-progress: source
> exists but there is **no Gradle build system or CI pipeline** yet, so it does
> not build or ship. Treat it as a reference, not a supported client.
>
> To bring it into release scope you must add a Gradle wrapper + build config
> and a real CI job. Until then it is explicitly out of the release artifact.

Requires JDK 17.
